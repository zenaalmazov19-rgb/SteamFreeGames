# Steam Free Games

Android-приложение с быстрыми ссылками на бесплатные игры, Steam-карточки, раздачи и стоимость предметов.

## Возможности версии 2.0
- Тёмно-зелёный интерфейс.
- Разделы Steam-карточек, раздач, профиля и оценки предметов.
- Кнопка обновления открывает актуальную страницу раздач SteamDB.
- Локальная история игр, которые пользователь вручную отметил как полученные.
- Необязательное ежедневное уведомление-напоминание проверить раздачи.

Важно: приложение не получает автоматически персональный инвентарь или подтверждение выдачи игры. Данные о раздачах и ценах открываются на внешних сайтах. Уведомление напоминает проверить предложения; оно не гарантирует обнаружение новой раздачи.

## Сборка APK
В GitHub открой Actions → Build SteamFreeGames APK. После успешной сборки APK находится в Artifacts.
